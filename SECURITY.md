# Security Policy

## Supported versions

Security fixes are applied to the latest maintained ShioriBox release. Older versions may not receive fixes.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Contact the repository maintainer privately through the GitHub profile and include:

- A short description of the issue and its potential impact
- The affected ShioriBox version and Windows version
- Reproduction steps or a proof of concept, where safe to share

Please allow time for the issue to be reviewed before making it public.
